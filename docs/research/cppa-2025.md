# CPPA 2025 registry source notes

- Publisher: California Privacy Protection Agency
- Dataset: 2025 California Data Broker Registry CSV
- Download: <https://cppa.ca.gov/data_broker_registry/registry2025.csv>
- Registry page: <https://cppa.ca.gov/data_broker_registry/>
- Checked: 2026-10-03
- Reuse status: Review required before persisting or republishing records

## Observed file structure

The CSV begins with a field-guidance row, followed by the field names, then broker submissions. The first row is not a broker record. The parser locates the row whose first-column label normalizes to `Data broker name`, rather than relying on a hard-coded physical row number.

The observed file has 67 columns and 543 registry rows (checked 2026-10-03). Its first row contains field guidance, followed by the field names and broker submissions. The first several identify broker name, DBA, website, contact details, address, and a privacy-rights website; the remaining fields include statutory disclosures and consumer request metrics. Some metric column labels explicitly refer to 2023 even though this file is the 2025 registry snapshot. Treat it as a dated historical snapshot, not current membership. The collector preserves the complete row in memory as an observation so later normalization can be reviewed separately.

The guidance row includes the instruction “If not answered by DB, do not surface in website.” Those column-level restrictions must be respected in any public projection. The state's general conditions-of-use page describes public-domain reuse subject to law and third-party rights, but we found no dataset-specific license or reuse statement on the CPPA registry page. Broker-submitted fields may have separate privacy or republication considerations. Raw observations are not a public API response; only explicitly reviewed normalized fields may be exposed.

## Current connector boundary

`src/ingestion/sources/cppa-2025.ts` downloads and parses the official CSV when invoked. It emits observations only. It does not write to D1, publish broker details, or submit privacy requests. The source manifest remains `review-required` until source reuse terms are evaluated.

The dry-run preview validated all 543 rows from the live file on 2026-10-03. It printed aggregate run metadata only and discarded the observations without writing to D1. Current observation keys are derived from normalized name, website host, and duplicate encounter order; treat them as snapshot-local until a stable registration key strategy is reviewed before recurring persistence.
